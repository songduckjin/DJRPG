# 다크 판타지 방치형 RPG (가제) 기획 메모

> 최초 작성: 2026-11-15

## 1. 확정된 기본 방향
- **장르**: 다크 판타지 방치형 RPG
- **레퍼런스 감성**: 디아블로 2 · 붉은보석(Red Stone) 스타일
- **그래픽**: 2.5D 쿼터뷰 (아이소메트릭 타일맵 + 다크 판타지 2D 스프라이트 + 횃불/스킬 조명 및 이펙트)
- **개발·배포 전략**:
  1. **완전 분리 프로젝트**: 기존 `puzzle-mates`와 별도 GitHub 비공개 레포로 운영
  2. **클라우드 워크플로우 (PC 미사용)**: GitHub 레포 + ChatGPT 클라우드 Codex + Vercel 자동 배포로 폰만으로 기획·구현·테스트 진행
  3. 웹(PixiJS 등 2.5D WebGL)으로 먼저 제작해 빠른 테스트·반복 개선 후 **Capacitor**로 Android / iOS 모바일 앱 패키징
  4. 리소스는 3D 모델링 대신 AI 생성 2.5D 스프라이트·타일셋 활용

## 2. 앞으로 정할 항목 (미정)
- [ ] **화면 방향**: 세로 화면(한 손 방치형) vs 가로 화면(시원한 쿼터뷰 시야)
- [ ] **코어 루프**: 자동 사냥 → 보스 게이지/소환 → 층 돌파, 오프라인 방치 보상 구조
- [ ] **아이템 파밍**: 등급(일반/마법/희귀/전설) 빛기둥 드랍, 방치형 필수 자동 분해/자동 장착 규칙
- [ ] **직업·스킬**: 초기 직업 수, 스킬 4~5슬롯 자동 발동, 변신/차지 같은 고유 시스템 여부
- [ ] **데이터 저장**: 로컬 + 클라우드(Turso 등) 연동 방식
