# [작업 193] DB 초기화 지연·일시 오류 완화

- **증상**: 2026-11-20 작업 191·192 배포 전후 운영 API가 간헐적으로 `503 DB_UNAVAILABLE`을 반환하고 첫 요청이 길게 지연됐다. 재확인 시 정상 `401 INVALID_TOKEN`으로 복구됐고, 연속 5회 요청은 0.05~0.64초였다.
- **목표**: DB 스키마 초기화의 정상 경로에서 예상 가능한 `ALTER TABLE` 실패와 전체 DDL 재실행을 제거한다. 첫 연결 실패 시에는 멱등 초기화만 짧게 재시도해 일시적 오류를 완화한다.
- **범위**: `server/database.mjs`, `tests/functions-adapter.test.mjs`, `docs/{CODE_MAP,QUICK_PATCH,TASK_193}.md`.
- **계약**: 기존 테이블·응답·에러 코드·세션·아이템 소유권 계약 유지. Turso 연결 정보는 로그·코드·커밋에 남기지 않는다.
- **겹침 확인**: 작업 146은 PR #91, 작업 191·192는 PR #123으로 병합됐다. 진행 중인 다른 작업과 수정 파일이 겹치지 않는다.
