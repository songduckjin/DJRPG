# [작업 202] 슬롯별 방치 시간·전 슬롯 방치 패키지·다이아 우편

- **목표**: 캐릭터 슬롯마다 방치 시간을 상단에 보여 주고, 각 슬롯에 입장할 때 보상을 회수한다. 전 슬롯 방치 30일 패키지 보유 시 접속 중인 캐릭터 외 모든 생성 슬롯을 자동 방치하며 개별 방치 버튼을 비활성화한다. 계정마다 다이아 1,000개를 우편으로 한 번 지급한다.
- **범위**: `docs/QUICK_PATCH.md`의 작업 202 행에 등록한 파일과 관련 테스트.
- **동작**: 방치 버튼은 기존처럼 슬롯에 입장한다. 패키지 구매 시 서버가 비접속 슬롯의 방치 시작 시각을 기록하고, 보상은 해당 슬롯 입장 후 기존 오프라인 정산으로 회수한다. 패키지 만료 뒤에도 만료 전 적립분은 보존한다. 슬롯 선택을 누르면 저장 확인 전부터 로딩 화면을 보인다.
- **다이아 우편**: 정식 계정에 한 번, 만료 없이 표시한다. 수령 시에만 원장과 지갑에 1,000개를 기록하고 같은 우편은 재지급하지 않는다. 기존 계정은 우편함을 처음 조회할 때 생성된다.
- **겹침 확인**: 작업 191·192의 PR #123과 작업 197의 PR #117은 병합됐다. 진행 중인 다른 작업과 수정 파일이 겹치지 않는다.
- **계약**: 계정 재화와 방치 권한은 서버 DB가 소유한다. 보상은 해당 슬롯 입장 후 기존 오프라인 정산 경로로 회수하며, 다이아 지급은 우편 수령 시 원장에 한 번만 기록한다.
- **검증**: TypeScript 검사, `shop`·`characters`·`journey`·`modal-ui`·`functions-adapter`·`market`·`market-actions`·`journey-ui` 관련 테스트 80건 통과 및 선택 즉시 로딩 단건 테스트 통과. `git diff --check` 통과.
