## [x] [작업 35] 층(스테이지) 선택 팝업 & 이동 기능 추가
- **등록일**: 2026-11-15
- **목표**: 사용자가 현재 도달한 최대 층(`maxFloor`) 이하의 원하는 층을 자유롭게 골라 파밍하거나 도전할 수 있도록 층 선택 팝업을 추가한다.

### 작업 내용
1. **상단 `층` 배지 클릭 → 층 선택 팝업 (`src/ui/interface.ts`, `src/styles/main.css`)**:
   - 상단 HUD의 `층 N` 표시를 클릭 가능한 버튼(`▾` 아이콘 또는 은은한 테두리)으로 만든다.
   - 클릭 시 `[층 선택]` 다크 판타지 모달이 열리며, 현재 도달한 최고 층(`maxFloor`)까지 1층부터 목록/그리드(한 줄에 4~5칸 또는 스크롤 카드)로 표시한다.
   - 각 층 버튼에는 **층 번호**, **권장 레벨 / 몬스터 강도**, **보스 층(예: 5층 단위) 👑 표시**, **현재 진행 중인 층 하이라이트**를 보여준다.
   - 아직 해금되지 않은 다음 층은 잠금(🔒) 처리하거나 현재 최고 층+1만 다음 도전으로 구분 표시한다.
2. **층 이동 및 자동 진행 옵션 (`src/game/store.ts`, `src/game/world.ts`)**:
   - 특정 층을 선택하면 `save.floor`를 해당 층으로 변경하고 필드의 기존 몬스터·드랍을 정리한 뒤 새 층 몬스터를 스폰하고 팝업을 닫는다.
   - `maxFloor`(역대 최고 도달 층) 필드를 `SaveData`에 추가/유지해(기존 세이브는 현재 `floor`를 `maxFloor`로 자동 보정), 낮은 층으로 내려가 파밍하더라도 이미 뚫어둔 최고 층 기록이 사라지지 않게 하고 DB에 저장한다.
   - (선택 편의) 팝업 상단이나 토글에 **"현재 층 반복 파밍(고정)" / "자동 등반"** 토글을 두어 원하는 층에서 계속 사냥하거나 계속 위로 올라갈 수 있게 한다.

## [x] [작업 37] 캐릭터 이동·전투 시 타깃 방향 바라보기 적용
- **등록일**: 2026-11-15
- **목표**: 캐릭터가 뒷걸음질하거나 엉뚱한 방향을 보고 걷지 않도록, **자동사냥 중에는 타깃 몬스터 방향**을, **수동 조이스틱 이동 중에는 이동 방향(또는 최근 타깃 방향)**을 바라보도록 좌우 반전(`facing`)을 동기화한다.

### 작업 내용
1. **시선(`facing`) 판정 보강 (`src/game/world.ts`, `src/game/render.ts`)**:
   - 자동사냥(`AUTO`) 중 타깃 몬스터가 있으면 이동 중이든 공격 중이든 **타깃 몬스터의 `x` 좌표와 플레이어 `x` 좌표 차이(`target.x - player.x`)**를 기준으로 즉시 좌우 방향(`facing = 1` 오른쪽 / `-1` 왼쪽)을 갱신한다(너무 미세한 떨림 방지를 위해 `Math.abs(dx) > 4` 이상일 때 전환).
   - 수동 조작 중에는 조이스틱/키보드 입력의 좌우 벡터(`vx`)가 `Math.abs(vx) > 0.05`일 때 이동 방향을 바라보게 하고, 멈춰서 공격할 때는 가장 가까운 타깃 쪽을 바라보게 한다.
   - `render.ts`에서 캐릭터 스프라이트 및 검기/공격 포즈의 `scale.x` 부호가 `player.facing`과 일관되게(기본 스프라이트 방향 기준으로 오른쪽/왼쪽 정확히 일치하도록) 반영되는지 확인·정리한다.

## [x] [작업 75] 고정 아레나 카메라 전환 및 캐릭터 직접 이동·경계 제한
- **등록일**: 2026-11-16
- **담당자**: 로컬 Codex
- **수정 파일**: `src/game/arena.ts`, `src/game/render.ts`, `src/game/render/entities.ts`, `src/game/world.ts`, `tests/arena.test.mjs`, `tests/world-movement.test.mjs`, `docs/TASK.md`, `docs/WORKLOG.md`.
- **목표**: 한 화면 고정 황야 배경 위에서 내 캐릭터가 항상 화면 정중앙에 박혀 서 있는 것처럼 보이던 현상과, 그로 인한 적 상대 속도 착시를 없애기 위해 카메라를 아레나 중심으로 고정하고 캐릭터가 화면 안을 직접 뛰어다니도록 전환한다.
- **수정 범위**: `src/game/render.ts`, `src/game/render/entities.ts`, `src/game/render/field.ts`, `src/game/world.ts` (및 관련 테스트).

### 작업 내용
1. **고정 아레나 카메라 투영 (`src/game/render.ts`)**:
   - `project(x, y)`에서 `world.player.x`, `world.player.y` 차감을 제거해 아레나 원점 `(0, 0)`이 화면 중심 `(cx, cy)`에 고정되게 한다:
     - `const project = (x: number, y: number): [number, number] => [cx + (x - y) * .86, cy + (x + y) * .43];`
   - `drawHero`, `drawRunes`, `drawVignette`에 넘기던 `(cx, cy)`를 **`const [hx, hy] = project(world.player.x, world.player.y)`**로 교체해 발밑 룬·시야 비네팅·캐릭터가 모두 캐릭터의 실제 화면 좌표를 따라다니게 한다.
   - `drawHero` 내부에서 `x, y`를 받아 그릴 때 `entities.ts`가 `cx, cy` 대신 전달받은 `x, y`를 그대로 쓰는지 확인한다.
2. **아레나 이동 가능 경계 클램프 및 스폰 위치 보정 (`src/game/world.ts`)**:
   - 내 캐릭터와 드랍·몬스터가 상단 HUD, 좌우 절벽 바위, 하단 메뉴·스킬 버튼 뒤로 벗어나지 않도록 아레나 이동 경계(예: 아이소메트릭 투영 기준 화면 안전 영역 또는 월드 반경 `|x| <= 125, |y| <= 155` 내외 클램프)를 적용한다.
   - 몬스터 스폰도 아레나 원점 기준 사방 가장자리(절벽 안쪽/가장자리)에서 자연스럽게 등장하도록 조정해, 적이 화면 밖에서 쏜살같이 달려드는 대신 아레나 안에서 캐릭터와 서로 마주 걸어가며 교전하게 만든다.

### 검증 및 완료 기준
1. 캐릭터 이동 시 화면 상 좌표(`project(player.x, player.y)`)가 실제로 이동하고, 적 이동 시 상대 속도 왜곡이 없음을 단위 테스트로 검증한다.
2. `pnpm run check`, `pnpm test`, `pnpm run build` 통과.
3. `docs/TASK.md`의 이번 작업을 `[x]` 처리하고 `docs/WORKLOG.md` 상단에 5줄 이내 기록.
4. **토큰 절약**: 브라우저 실기 테스트는 실행하지 않는다.
