## [x] [작업 1] 세로형 2.5D 다크 판타지 전사 프로토타입 (직접 이동 + 스킬 3종 + 하단 인벤토리)
- **등록일**: 2026-11-15
- **목표**: 모바일 세로형 화면 상단에서는 전사를 직접 조작해 사방에서 몰려오는 몬스터를 기본 공격 + 스킬 3개로 쓸어담고, 하단 인벤토리에서 드랍된 장비를 바로 장착·분해할 수 있는 2.5D 쿼터뷰 맛보기 플레이어블 빌드 구축.

### 작업 내용
1. **프로젝트 초기 세팅 (Vite + TypeScript + PixiJS)**:
   - `package.json`, `tsconfig.json`, `vite.config.ts`, `index.html`, `src/main.ts` 구성 (`pixi.js` 안정 버전 사용).
   - `npm run build` 및 TypeScript 엄격 타입 체크 통과.
   - **세로형 모바일 분할 레이아웃**: `100dvh` 세로 풀스크린(`user-scalable=no`, 데스크톱에서는 중앙 모바일 비율 프레임 지원)을 **상단 전투 뷰(~62%) + 하단 인벤토리 패널(~38%)**로 분할 배치.

2. **2.5D 쿼터뷰 다크 던전 & 사방 몰려오는 몬스터 (`src/game/`)**:
   - 어두운 고딕 석조 아이소메트릭(마름모) 바닥 그리드 + 흔들리는 횃불 조명·비네팅으로 디아블로 2/붉은보석 분위기 구현.
   - **플레이어 캐릭터**: **인간 전사(Warrior)** 1종 (남/여 성별 선택 가능 — 장비 미착용 시 **남자는 팬티만 입은 맨몸**, **여자는 기본 심플 복장**으로 시작하며, 하단 인벤토리에서 투구·갑옷·무기를 장착하면 캐릭터 외형에도 실시간 반영, 이동 방향 바라보기, 추후 AI 스프라이트로 교체 가능하도록 구조 분리).
   - **적 스폰 구도**: 플레이어 주변 사방(화면 바깥 360도 방향)에서 **해골전사(Skeleton Warrior)** 몬스터가 끊임없이 스폰되어 플레이어를 향해 몰려옴. 일정 처치 수마다 **거대 해골 군주(보스)** 등장.

3. **전투 영역 조작계 (직접 이동 + 우측 기본공격·스킬 3개)**:
   - **이동 조작 (전투 영역 좌측 하단)**: 터치 드래그 가상 조이스틱으로 전사를 자유롭게 이동 (`WASD`/방향키 테스트 지원 포함, 캔버스 `touch-action: none`).
   - **공격 & 스킬 버튼 (전투 영역 우측 하단)**: 엄지손가락이 닿기 편한 배치로 **기본 공격 1개 + 스킬 3개** 구현:
     - **기본 공격**: 바라보는 방향(또는 가장 가까운 적 방향) 부채꼴 검기 베기, 짧은 쿨타임, 누르고 있으면 연속 공격.
     - **스킬 1 (회전 베기)**: 캐릭터 주변 360도 원을 그리며 회전 검기 광역 피해.
     - **스킬 2 (대지 강타)**: 전방/주변 바닥을 내리쳐 붉은 균열 이펙트와 함께 광역 피해 + 적 넉백.
     - **스킬 3 (전투 함성 / 광폭)**: 일정 시간 공격력·이동속도 상승 오라 + 주변 적 밀어내기.
   - 각 스킬 버튼에는 쿨타임 오버레이/남은 초 표시.
   - 전투 영역 상단: 현재 층/처치 수/레벨·경험치 바/골드, 붉은 HP·푸른 MP/CP 구슬(또는 컴팩트 바)을 조작부와 겹치지 않게 배치.

4. **아이템 빛기둥 드랍 & 하단 인벤토리 패널 (`src/ui/`, `src/game/store.ts`)**:
   - 몬스터 처치 시 경험치·골드 획득 및 확률로 바닥에 등급별 수직 **빛기둥**(일반 흰색 / 마법 파란색 / 희귀 노란색 / 전설 주황색) 장비 드랍 → 캐릭터가 근처로 이동하면 자동 획득되어 하단 인벤토리에 추가.
   - **하단 인벤토리 패널**:
     - **초기 상태**: 게임 시작 시 **장착 장비 0개·가방 아이템 0개**(완전 맨몸·맨손 기본 공격으로 시작).
     - **붉은보석식 전체 장착 슬롯**: **무기 · 보조무기(방패) · 투구 · 갑옷 · 목걸이 · 장갑 · 벨트 · 신발 · 반지1 · 반지2 (총 10칸)** 장착 공간과 총 공격력/방어력/체력 스탯 요약 제공 (세로 하단에서 보기 편하게 `[장비]`/`[가방]` 탭 전환 또는 상·하 배치).
     - 중단 그리드: 획득한 장비 슬롯 리스트(등급별 테두리 색 + 랜덤 옵션 부여 — 공격력/방어력/체력/치명타/공속 등 파밍 차이 발생), 아이템 터치 시 **현재 장착 중인 같은 부위 장비와 스탯 비교(▲상승/▼하락 표시)** 후 즉시 장착 또는 분해.
     - 하단/우측 액션: **일괄 분해**(일반·마법 등급 골드/강화석 변환) 버튼.
   - 레벨·골드·장비·층수 `localStorage` 자동 저장.

5. **초반 온보딩 튜토리얼**:
   - 처음 진입 시 맨몸·맨손 상태로 튜토리얼 배너 안내: ① 좌측 조이스틱으로 이동해 우측 기본 공격으로 첫 **해골전사** 처치 → ② 첫 처치 시 모든 유저에게 동일하게 **확정 드랍 `낡은 검`(일반 무기)** 빛기둥 생성 → ③ 획득 후 하단 인벤토리에서 **`낡은 검`을 터치해 무기 슬롯에 장착**하면 캐릭터 손에 검이 쥐어지며 튜토리얼 완료 (`localStorage`에 완료 상태 저장).

### 검증 및 완료 기준 (Codex Policy)
1. `npm run build` 성공 및 TypeScript 에러 0건.
2. `docs/TASK.md`의 이번 요청을 `[x]`로 표시하고 `docs/WORKLOG.md` 상단에 5줄 이내로 작업 요약 기록.
3. **토큰 절약**: 브라우저 실기 조작, Playwright/헤드리스 브라우저 실행, Computer Use 도구는 절대 실행하지 않고 `npm run build` 검증까지만 완료한다. (`AGENTS.md` 수칙 준수)

## [x] [작업 3] 붉은보석 스타일 2.5D 스프라이트 교체 · 자동사냥 AI · 하단 메뉴 팝업 개편
- **등록일**: 2026-11-15
- **목표**: 도형 기반 그래픽을 `public/assets/`의 고퀄 2.5D 다크 판타지 스프라이트·던전 타일로 전면 교체하고, 방치형 핵심인 **자동사냥(ON/OFF)**과 하단 **`[내 상태]` `[장비(팝업)]` `[스킬]`** 버튼 구조를 구현한다.

### 작업 내용
1. **고퀄 2.5D 스프라이트 & 던전 바닥 교체 (`public/assets/`)**:
   - 이미 커밋된 아래 에셋을 PixiJS `Assets.load`로 불러와 기존 도형(`Graphics`) 캐릭터·해골·바닥을 전면 교체한다:
     - `/assets/dungeon_tile.jpg`: 타일링 스프라이트(`TilingSprite`)로 어두운 고딕 석조 바닥 렌더링 + 횃불 광원·비네팅 오버레이로 붉은보석/디아블로2 분위기 극대화.
     - `/assets/warrior_male_base.png`: 남자 전사 기본 맨몸(팬티만 착용) 스프라이트.
     - `/assets/warrior_female_base.png`: 여자 전사 기본 복장 스프라이트.
     - `/assets/warrior_armored.png`: 갑옷·투구·무기 등 장비 장착 시 전환(또는 장착 부위 수/갑옷·무기 착용 여부에 따라 풀아머 전사 스프라이트로 업그레이드).
     - `/assets/skeleton_warrior.png`: 일반 해골전사 스프라이트.
     - `/assets/skeleton_boss.png`: 보스 거대 해골 군주 스프라이트.
   - 모든 캐릭터·몬스터 발밑에 부드러운 타원 그림자 추가, 이동 방향에 따른 좌우 반전(`scale.x` 부호), 공격/피격 시 스쿼시·플래시·넉백 모션 적용.

2. **방치형 자동사냥 AI (우측 작은 `AUTO` 버튼 컨트롤)**:
   - 전투 화면 **우측(스킬 버튼 위 또는 우측 가장자리)에 작은 `AUTO` 토글 버튼**을 배치한다.
   - **자동사냥 ON 동작**:
     - 주변에 떨어져 있는 빛기둥 아이템이 있으면 우선 가까이 이동해 자동 획득.
     - 가장 가까운 해골전사(또는 보스)를 추적해 공격 사거리 안으로 이동 후 **기본 공격 연타 + 쿨타임 완료된 스킬 3종(회전 베기·대지 강타·전투 함성)을 자동으로 시전**.
   - **수동 개입 시 즉시 해제 규칙**:
     - `AUTO ON` 상태에서 플레이어가 좌측 조이스틱이나 키보드로 **직접 이동 조작을 시작하면 즉시 `AUTO OFF`(자동사냥 해제)**로 전환된다(손을 떼도 자동으로 다시 켜지지 않음).
     - 다시 자동사냥을 하려면 우측의 작은 **`AUTO` 버튼을 직접 클릭**해 켜야 한다.

3. **하단 UI 개편 (`인벤토리 가방` + `[내 상태]` `[장비]` `[스킬]` 버튼 & 팝업)**:
   - 기존 화면 절반을 차지하던 상시 탭(`장비`/`가방`)을 정리해 **전투 화면 세로 비율을 더 넓히고**, 하단에는 **가방 그리드(드랍 아이템 즉시 확인/장착/일괄 분해)**와 함께 맨 아래(또는 가방 바로 위) 고정 버튼 바에 **`[내 상태]` · `[장비]` · `[스킬]`** 3개 버튼을 배치한다.
   - **`[장비]` 버튼 클릭 → 팝업(모달) 오픈**: 붉은보석식 **10칸 장착 슬롯(무기·보조무기·투구·갑옷·목걸이·장갑·벨트·신발·반지1·반지2)**과 총 스탯 요약을 팝업으로 표시(슬롯 터치 시 해제 가능).
   - **`[내 상태]` 버튼 클릭 → 팝업 오픈**: 현재 레벨, 경험치, 공격력/방어력/체력/치명타/공속 상세 스탯, **남/여 성별 전환** 버튼 표시.
   - **`[스킬]` 버튼 클릭 → 팝업 오픈**: 기본 공격 + 3종 스킬 설명·쿨타임·피해 계수 확인(골드/레벨로 스킬 강화 가능하면 더 좋음).
