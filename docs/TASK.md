# DJRPG 작업 지시서

---

## [작업 1] 세로형 2.5D 다크 판타지 전사 프로토타입 (직접 이동 + 기본공격·스킬 3개)
- **등록일**: 2026-11-15
- **목표**: 모바일 세로형 화면에서 전사 캐릭터를 직접 이동시키고, 사방에서 몰려오는 몬스터를 기본 공격 + 스킬 3개로 쓸어담는 2.5D 쿼터뷰 맛보기 플레이어블 빌드 구축.

### 작업 내용
1. **프로젝트 초기 세팅 (Vite + TypeScript + PixiJS)**:
   - `package.json`, `tsconfig.json`, `vite.config.ts`, `index.html`, `src/main.ts` 구성 (`pixi.js` 안정 버전 사용).
   - `npm run build` 및 TypeScript 엄격 타입 체크 통과.
   - **세로형 모바일 뷰포트**: `100dvh` 세로 풀스크린, `user-scalable=no`, `touch-action: none` 적용 (데스크톱에서도 세로 모바일 비율 또는 반응형 캔버스로 쾌적하게 동작).

2. **2.5D 쿼터뷰 다크 던전 & 사방 몰려오는 몬스터 (`src/game/`)**:
   - 어두운 고딕 석조 아이소메트릭(마름모) 바닥 그리드 + 흔들리는 횃불 조명·비네팅으로 디아블로 2/붉은보석 분위기 구현.
   - **플레이어 캐릭터**: **전사(Warrior)** 1종 (2.5D 프로시저럴 캐릭터/검·방패/망토 표현, 이동 방향 바라보기, 추후 AI 스프라이트로 교체 가능하도록 구조 분리).
   - **적 스폰 구도**: 플레이어 주변 사방(화면 바깥 360도 방향)에서 해골/임프 몬스터가 끊임없이 스폰되어 플레이어를 향해 몰려옴. 일정 처치 수마다 보스 몬스터 등장.

3. **모바일 세로형 조작계 (직접 이동 + 우측 기본공격·스킬 3개)**:
   - **이동 조작 (좌측 영역)**: 화면 왼쪽 하단(또는 왼쪽 절반 터치 드래그) 가상 조이스틱으로 전사를 자유롭게 이동 (`WASD`/방향키 테스트 지원 포함).
   - **공격 & 스킬 버튼 (우측 하단)**: 엄지손가락이 닿기 편한 아치형/부채꼴 배치로 **기본 공격 1개 + 스킬 3개** 구현:
     - **기본 공격**: 바라보는 방향(또는 가장 가까운 적 방향) 부채꼴 검기 베기, 짧은 쿨타임, 누르고 있으면 연속 공격.
     - **스킬 1 (회전 베기)**: 캐릭터 주변 360도 원을 그리며 회전 검기 광역 피해.
     - **스킬 2 (대지 강타)**: 전방/주변 바닥을 내리쳐 붉은 균열 이펙트와 함께 광역 피해 + 적 넉백.
     - **스킬 3 (전투 함성 / 광폭)**: 일정 시간 공격력·이동속도 상승 오라 + 주변 적 밀어내기.
   - 각 스킬 버튼에는 쿨타임 오버레이/남은 초 표시.

4. **아이템 빛기둥 드랍 & HUD**:
   - 몬스터 처치 시 경험치·골드 획득 및 확률로 바닥에 등급별 수직 **빛기둥**(일반 흰색 / 마법 파란색 / 희귀 노란색 / 전설 주황색) 드랍 → 캐릭터가 근처로 이동하면 자동 획득 및 알림.
   - HUD: 상단 현재 층/처치 수/레벨·경험치 바/골드, 좌측·우측 조작부와 겹치지 않는 위치에 디아블로 감성의 붉은 HP·푸른 MP/CP 구슬(또는 컴팩트 게이지) 배치.
