# DJRPG 작업 지시서

---

## [작업 1] 2.5D 다크 판타지 쿼터뷰 방치형 RPG 초기 프로토타입 구축
- **등록일**: 2026-11-15
- **목표**: 폰 브라우저에서 바로 열어 디아블로 2 / 붉은보석 감성을 체감할 수 있는 초기 맛보기 플레이어블 빌드 구축 (추후 Capacitor 앱 패키징 전제).

### 작업 내용
1. **프로젝트 초기 세팅 (Vite + TypeScript + PixiJS)**:
   - `package.json`, `tsconfig.json`, `vite.config.ts`, `index.html`, `src/main.ts` 구성 (`pixi.js` v8 또는 v7 안정 버전 사용).
   - `npm run dev`, `npm run build` 정상 동작 확인 (Node ESM/TS 엄격 타입 체크 통과).
   - 모바일 웹뷰/앱 환경을 고려해 `100dvh` 전체 화면, `user-scalable=no`, `touch-action: none` 기본 적용.

2. **2.5D 쿼터뷰 다크 던전 씬 (`src/game/Scene.ts` 등)**:
   - 어두운 고딕 석조 아이소메트릭(마름모 타일) 바닥 그리드 렌더링 + 가장자리 비네팅·깜빡이는 횃불 조명 효과로 어둡고 묵직한 던전 분위기 구현.
   - 중앙 근처에서 **자동 이동·타겟 추적·기본 공격 & 광역 스킬**을 사용하는 플레이어 전사(프로시저럴 2.5D 도형/픽셀 스프라이트 스타일, 추후 실제 AI 스프라이트 교체 가능하도록 구조 분리).
   - 사방에서 스폰되어 다가오는 몬스터(예: 해골 병사, 임프 등) + 웨이브/보스 게이지(10마리 처치 시 보스 등장).

3. **아이템 빛기둥 드랍 & 자동 파밍 루프**:
   - 몬스터 처치 시 일정 확률로 바닥에 아이템 드랍: 일반(흰색), 마법(파란색), 희귀(노란색), 전설(주황색) 수직 **빛기둥(Beam)** 이펙트 표시 후 1~2초 뒤 자동 획득(플로팅 텍스트 알림).
   - 골드·경험치·레벨업(스탯 상승) 및 1층~무한 층 진행 상태 관리(로컬 저장 `localStorage` 자동 저장).

4. **디아블로/붉은보석 감성 HUD (HTML/CSS 오버레이 또는 Pixi UI)**:
   - 하단 좌측: **붉은 체력 구슬(HP Orb)**, 우측: **푸른 마나/CP 구슬(MP/CP Orb)**.
   - 하단 중앙: 자동 발동 스킬 4개 슬롯(쿨타임 게이지 표시, 터치 시 즉시 발동도 가능) + 상단 현재 층수·처치 수·골드·레벨 표시.

### 검증 및 완료 기준
1. `npm run build` 성공 및 TypeScript 에러 0건.
2. `docs/TASK.md`의 이번 요청을 `[x]`로 표시하고 `docs/WORKLOG.md` 상단에 작업 결과 요약 기록.
3. **토큰 절약 (Codex Policy)**: 브라우저 실기 조작, Playwright/헤드리스 브라우저 실행, Computer Use 도구는 절대 실행하지 않고 `npm run build` 검증까지만 완료한다. (`AGENTS.md` 수칙 준수)
